# Telas do produto

Prints reais do painel (2026-10-30), 1440×900 @2x e iPhone 390×844 @3x. Conta usada: Korza Brownies, nossa, e uma conta de teste.
Podem virar criativo, com o nome e o domínio de teste cortados quando aparecerem.

| Pasta / arquivo | Mostra | Uso |
| --- | --- | --- |
| `onboarding/01` a `05` | Plataforma, nome e loja, logo, barra de navegação, notificação de teste | Passo a passo do "veja seu app". Mostram um esqueleto de app, sem produto (`produto.md`, "Funil real") |
| `onboarding/iphone-*` | As mesmas etapas no celular | Reels e stories |
| `painel/campaign_preenchida.png` | Criação de push com preview no iPhone (texto de exemplo, nada enviado) | A tela mais forte para peça. A oferta é fictícia: trocar antes de usar em anúncio |
| `painel/customization.png` | "Seu app": banner de cupom, boas-vindas, banner do site, carrinho abandonado (em breve) | Visão geral dos recursos. Corta o card "Em breve" |
| `painel/audiences_create.png` | Filtros de público | Só com a ressalva: públicos estão liberados para poucas lojas |
| `painel/campaigns_import.png` | Importação por CSV | Interno ou educativo |
| `painel/customization_coupon-banner.png`, `customization_welcome-notification.png` | Editores | Conteúdo de produto |
| `painel/create-account.png` | Cadastro | Passo a passo |
